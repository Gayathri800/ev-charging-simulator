# EV Charging Station Simulator

A simple Python program that simulates an electric vehicle charging station.

## Features
- View 3 chargers (7 kW, 22 kW, 50 kW) and their status
- Charge a vehicle and watch the battery rise
- Cost calculation based on energy used
- Waiting queue for vehicles
- Session history saved in `sessions.csv`

## How to run
1. Install Python
2. Run: `python main.py`
3. Choose options from the menu

## Built with
Python (no extra libraries needed)
